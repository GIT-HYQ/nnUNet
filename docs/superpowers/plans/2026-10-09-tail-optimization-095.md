# Dataset1001 长尾优化冲 0.95（tail-optimization-095）

**立项**：2026-10-09，分支 `tail-optimization-095`（自 master 159e16d）
**目标**：66-case holdout 0.9281 → **0.95**（差 2.2pt）
**前置结论**：Dataset1001 已切换生产（Task 8，66=0.9281，32/32 类 ≥0.80）；NC 补充数据**搁置**（标注不符要求、无人力处理）——本方案全部杠杆在现有 480 例训练集 + 推理/训练侧闭环。

## 一、差距结构（2026-10-08 实测，66-case 严格口径）

| 指标 | 数值 |
|---|---|
| 均值 / 中位数 | 0.9281 / 0.9666 |
| ≥0.95 / <0.90 / <0.85 | 39 / 18 / **11** |

**长尾 11 例**（全部 ToothFairy2P_）：P_036=0.506（幻影）、P_341=0.737、P_067=0.743（漂移）、P_368=0.746（3 颗微小 GT）、P_527=0.780、P_378=0.818、P_342/P_413/P_090/P_134/P_323≈0.84–0.85；8 例 GT 牙数 ≤12（部分牙列/病态为主）。

**类层面**：8 类 <0.90 全为前磨牙/磨牙（最低 4/FDI14=0.856）；上颌 0.9237 < 下颌 0.9434。

**杠杆算术（what-if）**：

| 干预 | 66-case 均值 |
|---|---|
| 长尾 11 例 → 0.85 | 0.9403 |
| 长尾 11 例 → 0.90 | **0.9486** |
| 全体 <0.95 例 +2pt | 0.9361（不达标） |
| 长尾→0.90 + 中段 +2pt | 0.9533 |

**结论**：全局手段到不了 0.95；路径 = 修长尾（+1.5~2pt）为主 + 后段类改善（+0.5~1pt）为辅。NC 摘除后预期下调至 **0.94~0.952**（边缘），模型/推理轨权重上升。

- 1000 时代三分分解：漏检 37.9% / 残余 ID 错 32.2% / 幻影 30.0%，三族全部集中磨牙（漂移、智齿幻影、磨牙漏检同源）；后处理四规则全否决（安全空间 ≈0）。

- 次要空白：长尾 11 例 GT 质量未可视审计（P_368 三颗小 GT 324/1183/3959 vox 存疑）；架构仍 plain UNet 1000ep（本地 nnunetv2 无 ResEnc trainer，需 backport）。

## 三、波次计划（每波带门控）

### Wave 0 — 诊断（~1 天，CPU 为主）
1. 对 1001 输出（`eval/holdout_ensemble_noxmirror/predictions/`）重跑三分分解（漏检/ID/幻影 + 实例级），对比 1000 结构（磨牙集中度、L/R twin 消退程度）。坑：uint8 `g*33+s` 溢出，astype(int32)。
2. 长尾 11 例 GT 可视审计（含 P_368 小 GT、8 漂移 case、24 牙尺度幻影清单）→ 每 case 归因：幻影/漂移/漏检/GT 上限。
3. 产出：新错误配比 → 决定 Wave 1–3 配比。

### Wave 1 — 推理侧零训练（1–2 天）
- 智齿/后牙幻影**概率阈值门控**（1001 幻影占 ≥20% 错误体素才做，否则跳过）；
- sliding-window overlap 提升、final+best checkpoint 集成等免费项。
- 门控：66-case 零回退（无 case >0.005 降幅）才保留；否则整波放弃。

### Wave 2 — 数据轨（去 NC 版，~1 周）
1. GT 审计发现确证错误 → 按既有规则（仅剔确证）处理并同步 splits；
2. **部分牙列 oversampling 微调**：训练集内部分牙列 case（INSUFFICIENT 同分布 69 例）提采样权重，从现有 5 折 checkpoint 微调（非从零）；fold_0 试点 → 门控 → 补 4 折；
3. NC → **parked**（重启条件：有人力做重鉴定，或提供方回复协议；checklist 文档可随时发出）。

### Wave 3 — 训练轨升级（GPU 全空闲；fold_0 试点先行）
门控协议沿用 1001 fold_0 门控（best20 回退 ≤0.02 且 worst20 提升 ≥0.03）：
1. **1500ep 延长 + oversampling** 合并微调实验（fold_0 → 门控 → 4 折）；
2. **ResEnc backport**（官方 nnUNet v2.7 ResEncM trainer + `resencUNet_planner.py` 已在树内），与 `onlyMirror01` 组合（mirror_axes=(1,2) 不变）；fold_0 试点 → 门控 → 5 折（单折 ~48–60h，A10 22GB 足够）；
3. （若 NC 解冻）合并重训叠加胜出方案。

### 终评
四列对比口径不变（66/69/72 + 上/下颌 + 32 类），与 0.9281/0.9094 直接可比；报告并入 results 文档体系。

## 五、Wave 0 结论（2026-10-09 实测，脚本 `scripts/decompose_errors_1001.py`，产物 `tooth_3d_semantic/logs/err_decompose_1001{,_cases}.jsonl`）

**三分分解对比（66-case，总错误 2.88M → 2.20M，-24%）**：

| 家族 | 1000+assigner | 1001 raw | 变化 |
|---|---|---|---|
| 漏检 missed | 1.09M (37.9%) | 1.04M (**47.5%**) | 基本不变，升为第一大家族 |
| 幻影 phantom | 0.86M (30.0%) | 0.82M (**37.3%**) | 基本不变 |
| ID 错 idwrong | 0.93M (32.2%) | 0.33M (**15.2%**) | **-64%** |
| └ ±8 孪生 | ~682k（主体） | **7.9k (2.4%)** | **镜像修复生效，家族消灭** |
| └ 邻牙漂移 ±1 | — | **301k (idw 的 90%)** | 新的 ID 错主体 |

实例级：554 OK / 210 ID 错 / 5 缺失；幻影实例 148 个（37 万体素）。

**漂移链验证（11 个 drift case 逐例查标签集合）——根因确认**：漂移 case 全部是**部分牙列**（GT 12–27 类 vs 满弓 32），模型把"不存在的牙"按满弓先验补出来（phantom 标签：P_090 缺 17 类却多出 8 个幻影标签；P_413 GT 仅 12 类出 3 个幻影；P_067/P_323/P_342/P_253 同型），漏一颗牙导致全链 +1 漂移。**phantom 与 drift 在同一批 case 同源**：不是独立两个问题，而是"满弓先验 vs 部分牙列现实"的一个问题。

**漏检主力在满弓 case**（F_063 101k / F_030 97k / F_067 88k / P_387 79k / P_122 73k 体素），与长尾 dice 低分 case 不同批（大 case 漏检占比小不拉低均值）。

**对 Wave 1–3 配比的修订**：
1. Wave 1（幻影概率门控）权重**上升**：phantom 37% + 集中在部分牙列 case 的少数实例，门控目标明确；
2. Wave 2（部分牙列 oversampling）权重**上升**：漂移+幻影同源的根因是训练分布满弓主导，模型未学到"牙可以缺"——这是 in-house 最大杠杆（NC 本来就是补这个，parked 后只能靠 oversampling）；
3. Wave 3（ResEnc/1500ep）针对满弓漏检（现第一家族），维持主力不变。

**Wave 0.2 GT 审计焦点收窄**（可视审计仍需用户执行）：P_036（10 幻影实例）、P_368（6 幻影 + 3 颗小 GT 324/1183/3959 vox）、P_378（2 缺失实例）、P_527（17.9k 漏检/215 幻影 = 纯漏检型）。
