**立项**：2026-10-09，分支 `tail-optimization-095`（自 master 159e16d）
**目标**：66-case holdout 0.9281 → **0.95**（差 2.2pt）
**前置结论**：Dataset1001 已切换生产（Task 8，66=0.9281，32/32 类 ≥0.80）；NC 补充数据**搁置**（标注不符要求、无人力处理）——本方案全部杠杆在现有 480 例训练集 + 推理/训练侧闭环。

## 一、差距结构（2026-10-08 实测，66-case 严格口径）

| 指标 | 数值 |
|---|---|
| 均值 / 中位数 | 0.9281 / 0.9666 |
| ≥0.95 / <0.90 / <0.85 | 39 / 18 / **11** |

**长尾 11 例**（全部 ToothFairy2P_）：P_036=0.506（幻影）、P_341=0.737、P_067=0.743（漂移）、P_368=0.746（3 颗微小 GT）、P_527=0.780、P_378=0.818、P_342/P_413/P_090/P_134/P_323≈0.84–0.85；8 例 GT 牙数 ≤12（部分牙列/病态为主）。

**杠杆算术（what-if）**：

| 干预 | 66-case 均值 |

**结论**：全局手段到不了 0.95；路径 = 修长尾（+1.5~2pt）为主 + 后段类改善（+0.5~1pt）为辅。NC 摘除后预期下调至 **0.94~0.952**（边缘），模型/推理轨权重上升。

## 二、已知错误结构 + 认知空白

- 1000 时代三分分解：漏检 37.9% / 残余 ID 错 32.2% / 幻影 30.0%，三族全部集中磨牙（漂移、智齿幻影、磨牙漏检同源）；后处理四规则全否决（安全空间 ≈0）。

- 次要空白：长尾 11 例 GT 质量未可视审计（P_368 三颗小 GT 324/1183/3959 vox 存疑）；架构仍 plain UNet 1000ep（本地 nnunetv2 无 ResEnc trainer，需 backport）。

## 三、波次计划（每波带门控）

### Wave 0 — 诊断（~1 天，CPU 为主）
1. 对 1001 输出（`eval/holdout_ensemble_noxmirror/predictions/`）重跑三分分解（漏检/ID/幻影 + 实例级），对比 1000 结构（磨牙集中度、L/R twin 消退程度）。坑：uint8 `g*33+s` 溢出，astype(int32)。
2. 长尾 11 例 GT 可视审计（含 P_368 小 GT、8 漂移 case、24 牙尺度幻影清单）→ 每 case 归因：幻影/漂移/漏检/GT 上限。
3. 产出：新错误配比 → 决定 Wave 1–3 配比。

### Wave 1 — 推理侧零训练（1–2 天）
- 智齿/后牙幻影**概率阈值门控**（1001 幻影占 ≥20% 错误体素才做，否则跳过）；
- sliding-window overlap 提升、final+best checkpoint 集成等免费项。
- 门控：66-case 零回退（无 case >0.005 降幅）才保留；否则整波放弃。

### Wave 2 — 数据轨（去 NC 版，~1 周）
1. GT 审计发现确证错误 → 按既有规则（仅剔确证）处理并同步 splits；
2. **部分牙列 oversampling 微调**：训练集内部分牙列 case（INSUFFICIENT 同分布 69 例）提采样权重，从现有 5 折 checkpoint 微调（非从零）；fold_0 试点 → 门控 → 补 4 折；
3. NC → **parked**（重启条件：有人力做重鉴定，或提供方回复协议；checklist 文档可随时发出）。

### Wave 3 — 训练轨升级（GPU 全空闲；fold_0 试点先行）
门控协议沿用 1001 fold_0 门控（best20 回退 ≤0.02 且 worst20 提升 ≥0.03）：
1. **1500ep 延长 + oversampling** 合并微调实验（fold_0 → 门控 → 4 折）；
2. **ResEnc backport**（官方 nnUNet v2.7 ResEncM trainer + `resencUNet_planner.py` 已在树内），与 `onlyMirror01` 组合（mirror_axes=(1,2) 不变）；fold_0 试点 → 门控 → 5 折（单折 ~48–60h，A10 22GB 足够）；
3. （若 NC 解冻）合并重训叠加胜出方案。

### 终评
四列对比口径不变（66/69/72 + 上/下颌 + 32 类），与 0.9281/0.9094 直接可比；报告并入 results 文档体系。

## 五、Wave 0 结论（2026-10-09 实测，脚本 `scripts/decompose_errors_1001.py`，产物 `tooth_3d_semantic/logs/err_decompose_1001{,_cases}.jsonl`）

**三分分解对比（66-case，总错误 2.88M → 2.20M，-24%）**：

| 家族 | 1000+assigner | 1001 raw | 变化 |
|---|---|---|---|
| 漏检 missed | 1.09M (37.9%) | 1.04M (**47.5%**) | 基本不变，升为第一大家族 |
| 幻影 phantom | 0.86M (30.0%) | 0.82M (**37.3%**) | 基本不变 |
| ID 错 idwrong | 0.93M (32.2%) | 0.33M (**15.2%**) | **-64%** |
| └ ±8 孪生 | ~682k（主体） | **7.9k (2.4%)** | **镜像修复生效，家族消灭** |
| └ 邻牙漂移 ±1 | — | **301k (idw 的 90%)** | 新的 ID 错主体 |

实例级：554 OK / 210 ID 错 / 5 缺失；幻影实例 148 个（37 万体素）。

**漂移链验证（11 个 drift case 逐例查标签集合）——根因确认**：漂移 case 全部是**部分牙列**（GT 12–27 类 vs 满弓 32），模型把"不存在的牙"按满弓先验补出来（phantom 标签：P_090 缺 17 类却多出 8 个幻影标签；P_413 GT 仅 12 类出 3 个幻影；P_067/P_323/P_342/P_253 同型），漏一颗牙导致全链 +1 漂移。**phantom 与 drift 在同一批 case 同源**：不是独立两个问题，而是"满弓先验 vs 部分牙列现实"的一个问题。

**漏检主力在满弓 case**（F_063 101k / F_030 97k / F_067 88k / P_387 79k / P_122 73k 体素），与长尾 dice 低分 case 不同批（大 case 漏检占比小不拉低均值）。

**对 Wave 1–3 配比的修订**：
1. Wave 1（幻影概率门控）权重**上升**：phantom 37% + 集中在部分牙列 case 的少数实例，门控目标明确；
2. Wave 2（部分牙列 oversampling）权重**上升**：漂移+幻影同源的根因是训练分布满弓主导，模型未学到"牙可以缺"——这是 in-house 最大杠杆（NC 本来就是补这个，parked 后只能靠 oversampling）；
3. Wave 3（ResEnc/1500ep）针对满弓漏检（现第一家族），维持主力不变。

**Wave 0.2 GT 审计焦点收窄**（可视审计仍需用户执行）：P_036（10 幻影实例）、P_368（6 幻影 + 3 颗小 GT 324/1183/3959 vox）、P_378（2 缺失实例）、P_527（17.9k 漏检/215 幻影 = 纯漏检型）。

## 六、Wave 1 结果（2026-10-09，判死）

概率图导出（`scripts/export_probs_1001.py`，66 例 14.8 min，数值与生产预测逐体素一致）+ 幻影门控扫描（`scripts/sweep_phantom_gate_1001.py`）：

- **mean_maxprob 门控死**：τ≤0.50 时无任何幻影被移除（幻影组件与真牙同样自信）；τ≥0.70 开始伤真牙（worst −0.035）；τ=0.95 时 mean 跌至 0.9084。
- **信号存在但不可分**：幻影 151 组件 vs 真牙 881，AUC(maxprob)=0.873；幻影中位 maxprob 0.968 / 真牙 0.990，分布重叠严重（40% 幻影 ≥0.98）。**模型"自信地错"**——满弓先验以高置信度强加。
- 结论：与 1000 时代"后处理安全空间≈0"一致，现对 1001 概率图证实。推理侧不再投入。
- 产物：`eval/holdout_ensemble_noxmirror_probs/{probs,comps,segcheck}/`（npz 稀疏概率 + 组件置信统计，后续任何组件级规则可离线复用）。

## 七、Wave 2 前提推翻（2026-10-09 量化）

训练集（408 例 union）GT 类数分布：**满弓仅 16 例（4%）**；缺 ≥1 牙 392 例（96%）；<28 类 335 例；<20 类 161 例。与长尾 holdout case（5–25 类）同分布。

**原 Wave 2（部分牙列 oversampling）前提不成立，判死**——模型训练时见过大量部分牙列，仍幻影。真根因是 **patch 局部性**：nnUNet patch 只见局部弓段，"缺牙"是全局信息，patch 内缺口表现为"证据缺失"而非"牙缺失"，局部连续性先验自动补牙。

**替代杠杆（全部是从零重训级，~1 周/轮）**：
1. **严重度加权采样**：<20 类重度 case 提权（161 例可加权）——与原 oversampling 不同，是 severity 权重而非 presence 权重；
2. **缺口合成增强**：从满弓 case 抠掉一颗牙（图+标签同步置空）合成"有证据的缺牙"，直接教"缺口=无牙"（自定义 DA，nnUNet 无此变换）；
3. **更大上下文**：cascade（lowres+highres）或更大 patch / ResEnc 大 FOV——让"全局缺牙"可见。

## 九、gapcut fold_0 门控结果（2026-10-11，FAIL）

训练：1000 epoch，39.8h（143.2 s/epoch 均值），final val Dice **0.8125**（1001 fold_0 = 0.8185，−0.006 噪声级）。

**40-case 门控（单折 checkpoint_final，对照 1001 fold_0 同折）**：

| 准则 | 规则 | 1001 fold_0 | gapcut | 判定 |
|---|---|---|---|---|
| 1 | best20 ≥ 0.9855 − 0.02 | 0.9855 | 0.9827（−0.0028） | PASS |
| 2 | worst20 ≥ 0.8773 + 0.02 | 0.8773 | 0.8733（**−0.0040**） | **FAIL** |

**逐 case 结构（关键发现——机制按设计起效，但代价是召回）**：

- **目标家族（幻影/漂移）改善**：P_036 +0.043（幻影 case，0.486→0.528）、P_389 +0.025、P_122 +0.022、P_002 +0.019、P_542 +0.014、P_387 +0.007、P_368 +0.005；
- **召回家族（纯漏检）受损**：P_527 **−0.108**（纯漏检 case，17.9k 漏检体素，无幻影——"缺口=无牙"教得越狠，边界侵蚀越重）、F_003 −0.036、P_322 −0.035、P_079 −0.024、P_341 −0.020；
- 净效果 = 把 dice 从欠分割型 case 转移给幻影型 case，总和≈0。

**结论**：gapcut 方向对幻影家族有效（P_036 等 7 例全升），但单独使用使决策边界向"无牙"偏移，在 missed 已是第一家族（47.5%）的背景下净收益为负。**门控 FAIL，不铺 4 折**。gapcut 若复活需与召回侧对冲（降 p / 严重度 oversampling 配对），或等 missed 家族被容量/上下文杠杆（1500ep/ResEnc）压下去之后再叠加。

产物：`logs/gate_gapcut_fold0_raw.jsonl`；模型 `results/Dataset1001_ToothSemanticNoXMirror/nnUNetTrainer_onlyMirror01_gapcut__nnUNetPlans__3d_fullres/fold_0/`。

## 十、ResEncL fold_0 试点（2026-10-11 启动，进行中）

**选型理由**：patch [112,224,256] = 6.1M 体素 ≈ 3× plain UNet 上下文，直接治根因「patch 局部性 → 缺牙全局信息不可见」；同时针对第一家族 missed（47.5%，主力在满弓大 case）。ResidualEncoderUNet 6 stages、n_blocks (1,3,4,6,6,6)，官方 preset `nnUNetResEncUNetLPlans`（24GB 档）。

**配置**：planner 文件已 backport（官方 2.7.0 原样 + 一行 `resample_torch` import 修复）→ `nnunetv2/experiment_planning/experiment_planners/residual_unets/residual_encoder_unet_planners.py`；trainer 组合 `nnUNetTrainer_onlyMirror01`（mirror_axes=(1,2) 不变）；3 GPU DDP（1,2,3，GPU 0 留空）。

**坑**：plans 默认 batch_size 2 < 3 GPU → DDP 断言失败。手动 override batch 2→3（per-GPU local batch 1，实测 17.4GB/卡，余量充足）。override 只落在 preprocessed 目录的 plans json（gitignore 内），重规划需重打——脚本 `scripts/train_fold_resenc_l.sh` 头注释已记录。

**实测**：**198 s/epoch**（预估区间 185–215s 内）× 1000 epoch ≈ **55h**，ETA 10-13 深夜。train_loss 正常下降（epoch 3→5: 0.179→0.152）。

**门控**：训完后同口径 40-case 门控（对照 1001 fold_0：worst20 ≥ 0.8973 且 best20 ≥ 0.9655）。PASS → 铺 5 折（~11.5 天 3 GPU）+ 评估 gapcut 叠加复活条件；FAIL → 记录机制结论，转 gapcut v2 对冲版或 severity 加权采样。
